* Example: a thermostat
#+attr_latex: :options basicstyle=\ttfamily\footnotesize
#+begin_src lean
structure Thermostat where
  home : Nat
  away : Nat
#+end_src

Constraints:
- =5 ≤ home ≤ 30=
- =5 ≤ away ≤ 30=
- =away ≤ home=

* Last session: a refinement
#+attr_latex: :options basicstyle=\ttfamily\scriptsize
#+begin_src lean
def thermostatType : RefinedDataType thermostat :=
  .refine (.record fun _ => temperatureType)
    (.require (fun value => value .away ≤ value .home)
      (.natLe (.project awayTemperature) (.project homeTemperature))
      (.value "Away temperature must not exceed home temperature.")
      (.locations [awayTemperature.locationExpr])
      (by intro value; grind [Expr.eval, Path.get, awayTemperature, homeTemperature]))
#+end_src

* Plain Lean types
We define types with regular Lean code.

#+attr_latex: :options basicstyle=\ttfamily\footnotesize
#+begin_src lean
structure Thermostat where
  home : Nat
  away : Nat
  home_valid : 5 ≤ home ∧ home ≤ 30
  away_valid : 5 ≤ away ∧ away ≤ 30
  away_not_warmer : away ≤ home
  deriving FormModel
#+end_src

* Checks are expressed in Lean

#+attr_latex: :options basicstyle=\ttfamily\scriptsize
#+begin_src lean
instance : ConstraintRule Thermostat.Constraint.away_not_warmer where
  check parts :=
    if h : parts.away ≤ parts.home
    then .valid h
    else .invalid (proof := h)
                  (message := "Away temperature must not exceed home temperature.")
                  (targets := locations[Thermostat.Field.away])
#+end_src

- The same implementation is run by the server *and* the browser.

* Validated values
#+attr_latex: :options basicstyle=\ttfamily\footnotesize
#+begin_src lean
class FormModel (model : Type) where
  Raw : Type
  erase : model → Raw

abbrev Validated (model : Type) [FormModel model] (raw : FormModel.Raw model) :=
  { value : model // FormModel.erase value = raw }

class Validation (model : Type) [FormModel model] where
  validate : (raw : FormModel.Raw model) →
    Except (List (Error raw)) (Validated model raw)
#+end_src

* Generated: =Validation Address=
#+attr_latex: :options basicstyle=\ttfamily\footnotesize
#+begin_src lean
instance
  [ConstraintRule Address.Constraint.street_valid] -- defined by user
  [ConstraintRule Address.Constraint.number_valid] -- defined by user
  : Validation Address
#+end_src

- Recursively validates every field, then runs every rule.
- If a rule is missing we get a compiler error.

* =deriving FormModel=: summary
Summary:
- =Address.Raw=: the data without proofs, with JSON.
- =Address.erase=: forgets the proofs.
- =Address.Field=: typed field names.
- =Address.Constraint=: one per proof field.
- =Validation Address=: checks every constraint.

* Constraint rules
One rule per proof field.@@latex:\footnote{Simplified: In real code \texttt{check} receives the \texttt{Thermostat.Parts}, not \texttt{Thermostat.Raw}.}@@

#+attr_latex: :options basicstyle=\ttfamily\footnotesize
#+begin_src lean
inductive Decision (property : Prop) {α : Type} (value : α) where
  | valid (proof : property)
  | invalid (proof : ¬ property) (message : String) (targets : Targets α value)
#+end_src

- A check is proven correct.
- Error targets are typed locations inside the value.

* Error targets
- An error can be global or local:
#+attr_latex: :options basicstyle=\ttfamily\scriptsize,aboveskip=4pt,belowskip=4pt
#+begin_src lean
inductive Targets (α : Type) (value : α) where
  | global
  | local (locations : { l : List (Location value) // l ≠ [] })
#+end_src

* Location
- A valid location for a concrete value:
#+attr_latex: :options basicstyle=\ttfamily\scriptsize,aboveskip=4pt,belowskip=4pt
#+begin_src lean
inductive Location : {α : Type} → α → Type 1 where
  | self : Location value
  | field
    (field : Fields.Field α β)
    (rest : Location (Fields.get field value))
    : Location value
  | index
    (position : Fin value.length)
    (rest : Location (value.get position))
    : Location value
  | constructor
    (constructor : Constructors.Constructor α β)
    (rest : Location value)
    : Location (Constructors.inject constructor value)
#+end_src

* Lean → React: snapshot
#+attr_latex: :options basicstyle=\ttfamily\scriptsize
#+begin_src lean
structure Snapshot (α : Type) where
  view : View               -- the tree to render
  controls : List Control
  value : α
  ui : Interaction.State    -- pending, notice, rejection, ...
  errors : List Error
  submit : Bool             -- React must send the value
#+end_src

- Sent as JSON (=Wire.Snapshot=); its TypeScript type is generated.
- React only renders =view= and sends the submission.

* The cost
1. =forms.wasm=: 5.85 MiB, 1.10 MiB with gzip, 0.68 MiB with Brotli.
2. Lean runtime patched to build with Emscripten.
3. We can't run anything that depends on =libuv= on the browser side:
   - Timers.
   - Async tasks.

New dependencies:
1. =lean=
2. Emscripten (which bundles =clang=)
3. CMake, Python 3 and =patch= to build them.

* Summary
1. The client is Lean compiled to WebAssembly.
2. =DataType=, =Expr= and =Checker= are gone: constraints are written in normal Lean.
3. One source of logic truth for client and server.
4. Forms describe ordinary Lean types.
